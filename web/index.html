使用帮助
① 选择生成模式：快速 / 高质量；网页自动绑定工作流：无图=文生图 · 有图=图片编辑（细）· 有图+透明PNG=移除背景 · 无图+提示词优化=文生图带优化
② 写描述后输入 @ 弹出菜单，点选后插入内嵌小图引用（双击图块可移除）；参考图可拖拽排序，拖新图到缩略图直接替换该位置图片
③ 快捷创作：换装 / 替换 / 全景单片 / 多视角多图 / 参考图放大 / 人物三视图；多视角多图为每角度独立提交一次生成，参考图放大为每张参考图直接放大，人物三视图为三个视角合成在一张图上
④ 每张参考图 🖌：画笔标记区域，保存后该区域按提示词局部重绘；负面提示词框（可选）只进负面，绝不串到正面，抠图模式无需填写
⑤ 种子旁的高清放大开关：生成/编辑完成后自动对每张结果追加 VOSR2 放大（2×/3×/4×）；透明PNG 抠图不可用放大；「参考图放大」快捷方式直接放大参考图
⑥ 任务实时显示总进度条 + 当前阶段文字（如"AI 文本编码…"），缩略图为AI 创作等待动画；完成后自动归档到创作记录
⑦ 创作记录点开出现该次任务的全部图片，可逐张下载或全部下载；灯箱支持滚轮缩放 + 按住随意拖动
⑧ 访问口令为可选：后端未配置口令时开箱即用；部署方设置了口令才需点击右上角 🔑 填写
外部 API 调用
部署完成后，外部程序可用 HTTP 接口直接调用生成，无需打开页面。接口路径与请求体如下（示例 JSON 可一键复制）：
POST /api/generate
提交一个生成任务，返回任务 ID；参考图以 base64 dataURL 传入，最多 10 张，可携带画笔蒙版。
请求头 Authorization: Bearer <访问口令>
请求体（JSON）：
{
  "prompt": "雨夜霓虹招牌倒影，电影感",
  "negative_prompt": "多余的手指, 坏手, 模糊",   // 可选：负面提示词（只进负面）
  "model": "fast",            // fast=INT8 快速 | hq=BF16 高质量
  "ratio": "16:9",            // 1:1 4:3 3:4 3:2 2:3 16:9 9:16
  "resLv": 0,                 // 0=官方原生 | 480|720|1080|1440|2560|4096（4K 实验档）
  "steps": 28,
  "cfg": 3.0,                 // 高级参数：CFG 引导强度（与 ComfyUI 一致）
  "sampler": "euler",         // 采样器：euler|euler_ancestral|dpmpp_2m|dpmpp_2m_sde|dpmpp_3m_sde|uni_pc
  "scheduler": "simple",      // 调度器：simple|normal|karras|exponential|sgm_uniform
  "denoise": 1.0,             // 重绘幅度 0.3~1.0（i2i/编辑时有效）
  "seed": null,               // 可选，null=随机
  "count": 1,                 // 1|2|4（多视角时每视角 1 张）
  "transparent": false,       // true = 透明PNG 抠图（有图时绑「移除背景」工作流）
  "optimize": false,          // true = 提示词优化（无图时绑「文生图带优化」工作流）
  "wf": "auto",               // auto|t2i|t2i_opt|i2i|rmbg|upscale（auto 按图/开关自动决策）
  "upscale": false,           // true = 生成完成后自动高清放大（VOSR2）；rmbg 不可用
  "upscale_scale": 2,         // 放大倍数 1~16（一般 2/3/4）
  "views": [],                // 多视角：["正面","左前45°",...] 每角度独立提交生成，全部完成才算 done
  "refs": [                   // 可选，最多 10 张
    {"name":"ref1.png","data":"data:image/png;base64,...","mask":"data:image/png;base64,..."}
  ]
}
→ { "taskId": "8f3a…", "status": "queued", "queue": 0 }
GET /api/task/{taskId}
轮询任务进度：返回状态 / 总进度 / 当前节点 / 预计剩余秒数。
→ { "status": "running", "pct": 42, "node": "采样生成", "etaSec": 18, "nodes": [{"id":"6","name":"采样生成","status":"running","pct":42}] }
GET /api/image/{taskId}
任务完成后下载生成图片（PNG，多张时按种子编号）。
→ 200 image/png（图片二进制）
POST /api/restart
管理接口：卸载模型并重启生成服务（与顶部「重启服务」按钮相同，需管理员口令）。

🔑 访问口令

访问口令为可选：后端未配置口令时开箱即用，无需填写。仅当部署方在启动命令里设置了 API_TOKEN 才需要在此输入对应口令。

⚙ AI 提示词优化设置

开启「AI优化」后，点击该按钮会调用 AutoDL 大模型 API 优化当前提示词：文生图只发文本；图生图会把参考图按顺序发给 AI。优化结果填入提示词框供你检查，确认后再点「加入生成队列」。技能（Skills）保存在服务器，可自行修改，重启不重置。

— 令牌仅保存在服务器配置文件，不在网页中回显

接口地址已封装为 AutoDL Art 大模型内部 API，无需填写外部链接，仅需令牌与模型。

🖌 画笔编辑蒙版

笔刷 30
在图片上涂画需要修改的区域，保存后缩略图会显示蒙版叠加预览；生成时该区域按提示词局部重绘。 示例：涂在衣服上 → 提示词写「把衣服换成红色风衣」。
